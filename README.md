# ALingqing

Minecraft 服务端插件开发者，主要用 Java，偶尔写 JavaScript。

维护 Chenray 服务器（[chenray.top](https://www.chenray.top/)），也在 SpigotMC 上发布过插件。

## 主要项目

- [NoteBox](https://github.com/ALingqing/NoteBox) — Spigot/Paper 音乐插件，内置音频引擎播放 NBS 格式音乐，无外部依赖
- [AntiLitematica](https://github.com/ALingqing/AntiLitematica) — 从数据包层面检测并拦截 Litematica 自动建造
- [RideAllMobs](https://github.com/ALingqing/RideAllMobs) — 兼容 Bukkit/Spigot/Paper/Purpur/Leaves/Folia 的骑乘插件
- [geysermenu](https://github.com/ALingqing/geysermenu) — 通过 Geyser API 为基岩版玩家提供表单菜单
- [Metro-Altroutes](https://github.com/ALingqing/Metro-Altroutes) — Metro 地铁线路状态管理与停运换乘建议
- [WeComBot](https://github.com/ALingqing/WeComBot) — 企业微信通用消息桥接器

## 技术栈

- Java，Bukkit / Spigot / Paper / Folia 插件开发
- Minecraft Forge 模组
- JavaScript / Node.js
